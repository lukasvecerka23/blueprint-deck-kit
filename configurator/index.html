Blueprint Deck configurator

Configure your Blueprint Deck

Describe the interactive diagram you want: one offline HTML file with a pan-and-zoom map, clickable boxes, tabs, personas, a guided tour and a built-in editor. This form writes the diagram.config.yaml and the prompt for your coding agent (Claude Code, Codex, GitHub Copilot or any other agent with the skill installed). The defaults are sensible; change what matters to you. Your answers stay in this browser.

Theme preview

A real Blueprint Deck (the Acme example) in your theme. It is live: click around.

The live preview isn't available here (it needs the kit's examples/ folder next to configurator/). Everything else works.

Your configuration

Paste the prompt into your agent, in the repository you want a diagram for.

The prompt needs the blueprint-deck skill in your agent. Not installed yet? Install it first, once per machine.


              
The prompt contains the whole configuration, so it works in any agent. In Claude Code you can also save the file as diagrams/diagram.config.yaml and type /blueprint-deck diagrams/diagram.config.yaml.

Install the skill

        
Once per machine: installs the blueprint-deck skill for your agents.

      

      

        
macOS / Linux

        
curl -fsSL https://blueprintdeck.dev/install.sh | sh
          

        
Windows (PowerShell)

        
irm https://blueprintdeck.dev/install.ps1 | iex
          

        
Source, docs and examples: github.com/lukasvecerka23/blueprint-deck-kit
